# 跑步姿势识别项目

基于深度学习的跑步姿势识别系统

## 项目结构

```
running/
├── datasets/            # 数据集目录
│   ├── good/            # 正确跑步姿势
│   ├── bad/             # 错误跑步姿势
│   └── ...              # 其他姿势类别
├── templates/           # Web界面模板
│   └── camera.html      # 相机界面
├── 1.遍历文件夹图片.py    # 数据集处理脚本
├── 2-1.数据增强.py      # 数据增强脚本
├── 2.按角度旋转照片.py    # 图像旋转处理
├── 3.数据标记.py        # 数据标记工具
├── 4.训练模型.py        # 模型训练脚本
├── 5.实时跑步姿势识别.py   # 实时识别应用
├── 5-1.图片姿势测试.py    # 图片测试工具
├── 5-2.改进实时姿势识别.py # 改进版实时识别
├── 5-3.简化姿势识别.py    # 简化版识别
├── 5-4.混合姿势识别.py    # 混合识别方法
├── actioncnn.py         # 模型定义
├── actiondataset.py     # 数据集处理
├── app_ultra_stable.py  # 超级稳定的Web应用
├── RunningPoseModule.py # 跑步姿势检测模块
└── actioncnn.pt         # 训练好的模型
```

## 流程说明

1. **数据准备**：收集跑步姿势的图片数据
2. **数据处理**：使用脚本进行数据增强和预处理
3. **模型训练**：训练深度学习模型
4. **模型测试**：使用测试脚本验证模型性能
5. **实时应用**：部署到Web应用中进行实时识别
